Getting Thousands of Free Puzzles

You can add hundreds of extra puzzles directly into this single file's JavaScript array!


1. Official Lichess Database (Free):
  • Download: https://database.lichess.org/lichess_db_puzzle.csv.zst
  • Contains millions of puzzles with FENs, move sequences, and tags (e.g., mateIn1, mateIn2).
2. Free Lichess Daily API:
  • Endpoint: https://lichess.org/api/puzzle/daily
  • Returns JSON with initial FEN and exact solution moves in UCI format (e.g. e2e4).
3. How to format in code:

Add items to the PUZZLE_DATABASE array inside the <script> tag:

{ fen: "...", moves: ["e7e8q"], desc: "Mate in 1" }
